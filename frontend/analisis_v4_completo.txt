🔴 NUEVO #1: fetch SIN AbortController
─────────────────────────────────────────────────────────────────────────────
UBICACIÓN: Líneas 660-683

TEXTO EXACTO:
  const res = await fetch("https://api.open-meteo.com/v1/forecast?latitude=6.2442&longitude=-75.5812&current=...");

PROBLEMA: fetch sin AbortController no puede cancelarse. Si el componente se desmonta durante fetch, memory leak.

FIX:
  const controller = new AbortController();
  const res = await fetch(url, { signal: controller.signal });
  return () => controller.abort();


🔴 NUEVO #2: parseFloat(weather.visibility) PUEDE SER NaN
─────────────────────────────────────────────────────────────────────────────
UBICACIÓN: Línea 887

TEXTO EXACTO:
  value: parseFloat(weather.visibility),

PROBLEMA: Si visibility es "--", parseFloat("--") = NaN. UI muestra "NaN km".

FIX:
  value: weather.loading ? 0 : parseFloat(weather.visibility) || 0,


🔴 NUEVO #3: toFixed EN VALOR FALSY (0)
─────────────────────────────────────────────────────────────────────────────

    : "10.0",


🔴 NUEVO #4: new Date().getHours() SIN TIMEZONE
─────────────────────────────────────────────────────────────────────────────
UBICACIÓN: Línea 668

TEXTO EXACTO:
  const h = new Date().getHours();

PROBLEMA: Usa hora LOCAL del cliente. Si está en Tokyo, pide índice 14 para datos de Medellín.

FIX:
  const h = new Date().toLocaleString('en-US', { timeZone: 'America/Bogota', hour: 'numeric' }).split(' ')[0];

🔴 NUEVO #6: fmt FUNCIÓN INLINE CON TERNARIOS ANIDADOS
─────────────────────────────────────────────────────────────────────────────
UBICACIÓN: Línea 699

TEXTO EXACTO:
  const fmt = (n, d=0) => V ? "--" : (typeof n === "number" ? n.toFixed(d) : n);

PROBLEMA: Si n es NaN, typeof NaN === "number" es true, pero NaN.toFixed() = "NaN".

FIX:
  const formatValue = (value, decimals = 0) => {
    if (isLoading) return "--";
    if (typeof value !== "number" || isNaN(value)) return "--";
    return value.toFixed(decimals);
  };
